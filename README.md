# ReservaQuadras
Uma API direcionada a permitir a reserva e visualização de reservas de quadras, inicialmente direcionado às quadras do IFNMG Campus Salinas. Projeto criado para o desenvolvimento do trabalho final da disciplina de WEB II, do curso Bacharelado em Sistemas de Informação.
